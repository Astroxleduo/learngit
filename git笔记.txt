1、初始化一个新仓库
git init

2、配置用户信息
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

3、添加文件到暂存区
git add 文件名

4.提交更改
git commit -m "提交描述"

5、查看提交历史
git log
git log --stat

6、通过commit_id查看修改内容
git diff commit_id

7、代码回溯
git reset --hard [commit id]	第一个是当前分支回退到指定位置，会丢弃后面提交。
git checkout [commit id]	第二个是签出一个新分支

8、查看当前项目里有哪些分支
git branch

9、创建分支
git checkout -b 分支名

10、切换分支
git checkout 分支名

11、合并分支
git merge 被合并的分支名

12、把远程git仓库克隆到本地
git clone 远程仓库地址

13、把一个远程仓库绑定到本地仓库
git remote add <远程仓库别名> <远程仓库地址>

14、把编写的本地代码，推送到远程仓库
git push 远程仓库别名 远程仓库代码分支
git push 把代码上传到默认远程仓库中和本地分支对应的分支里

15、把远程代码，下载到本地
git pull 把默认远程仓库中对应分支的最新代码拉取下来
git pull 远程仓库别名 远程仓库代码分支

16、登录并校验权限
HTTPS+账号密码(pass away）
用户名+PAT令牌:
Settings->Developer Settings->Personal access tokens->Fine-grained tokens->Generate new token
SSH+密匙:
1、git remote add <远程仓库别名>  ssh的地址
2、ssh-keygen -t rsa -C 邮箱      ssh-keygen -t ed25519 -C "your_email@example.com"
3、public key has been saved in 目录id_rsa.pub
4、复制id_rsa.pub
5、Settings->SSH and GPG keys-> New SSH key

ps:使用 SSH 替代 HTTPS
# 1. 生成 SSH 密钥（如果还没有）
ssh-keygen -t ed25519 -C "your_email@example.com"

# 2. 将公钥添加到 GitHub
cat ~/.ssh/id_ed25519.pub
# 复制输出内容到 GitHub Settings > SSH and GPG keys

# 3. 修改远程 URL 为 SSH 格式
git remote set-url learngit git@github.com:Astroxleduo/learngit.git

# 4. 再次尝试推送
git push --set-upstream learngit leduo


个人大致使用流程：

创建绑定仓库->切换到develop分支->编写代码->执行git add * 暂存
->执行git commit 提交->切换回master分支->执行git merge 合并代码
->执行git push 推送

-每次修改留下记录
-随时查看修改内容
-随时切回旧版本代码
-保存多份 代码安全
